DEAL DEATH Launcher
1. Install Node.js 18+.
2. In this folder run:  npm install
3. Then run:            npm start
Replace assets/logo.png with your own logo (or change the path in index.html and app.js).
Settings (gear, bottom of sidebar) holds account name, instances folder and CurseForge key.
Instances are stored locally (localStorage). Minecraft download/launch is NOT implemented.

Installed content is saved in the app's user-data folder: <userData>/instances/<instance id>/ (use Files > Open folder inside an instance).
CurseForge needs a free API key from console.curseforge.com (paste it in the Content Hub filters panel).
